Jannat IT WordPress Theme
============================
Version 1.0.0

Designed for JannatIT.net: hosting, VPS, RDP and cloud services.

INSTALL:
1. WordPress Admin > Appearance > Themes > Add New > Upload Theme.
2. Upload jannatit.zip.
3. Activate the theme.
4. Set a static homepage if needed: Settings > Reading.
5. Replace the example pricing/order links with your WHMCS URLs.
6. Add your logo through Appearance > Customize > Site Identity (classic customizer support) or your site's logo controls.

NOTE:
The supplied Claude Artifact URL could not be externally fetched, so this package is a clean Jannat IT implementation based on the available Jannat IT branding context rather than a pixel-perfect conversion of that private artifact.
